## 装完的三步

1. 打开「说英文」App → **允许麦克风和语音识别**
   （键盘扩展自己弹不出权限框，只能在 App 里给一次）
2. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → **说英文**，
   然后点进它把「**允许完全访问**」打开（不开就发不出网络请求）
3. 回 App 点「**测一次**」，三条判据全绿再去用

## 怎么用

任意输入框 → 长按 🌐 切到「说英文」→ 点麦克风说中文 → 再点一下停 → **英文直接上屏**。

上排四个档位：工作 / 邮件 / 随意 / 正式。

## 🚨 两条路，因为录音这条我验不了

**主路径**：键盘里直接录音（跟 Typeless 一样）。

**兜底路径**：如果键盘里开不了录音（Apple 论坛上 `AVAudioSession` 报错是常见故障），
用**系统键盘的 🎤** 把中文说进输入框，再切到「说英文」点「**译光标前的中文**」——
这条不依赖录音权限，一定能用。

失败时界面会**写清卡在哪一步**（语音识别权限 / 麦克风权限 / 音频会话 / 录音引擎），
你截那一屏给我就能定位。我没有 iOS 设备，这一步只能在你手机上见分晓。

## 🚨 构建踩过的坑

**口令不能用 `strings` 去二进制里查。** `ALEX_PASS` 只有 14 字符，
Swift 的**小字符串优化**（≤15 字节）会把它编成指令里的立即数，不进 `__cstring`，
`strings` 永远找不到 —— 我第一版闸门就这么把一个好产物判成了 FAIL。
正解：在**生成 Secrets.swift 那一步**就地验源文件；二进制那道闸改查提示词（3588 字节，
一定在 `__cstring` 里），并配阴性对照。

**Secrets.swift 是 CI 生成的，不提交。** 口令走仓库 Secret `ALEX_PASS`，
值是从火山函数的环境变量直接读的，没经过 Kevin 的手。
