EXPLANATION LANGUAGE - read this before writing anything:
* The user block may contain a line `Explain in: <language>`.
  Every field whose job is to EXPLAIN (Chinese glosses, notes, roles, the check
  copy) must be written in THAT language.
* 🚨 If that line is absent or empty -> write the explanations in **Chinese**.
  That is the historical default and most users are Chinese speakers. Do not
  guess from the input language, do not ask, do not leave the field empty.
* 🚨 **Field names and markers never change.** A field is still called `zh` and
  the marker is still `<<<ZH>>>` even when the content is German. Those names
  are historical - read them as "the user's own language", not "Chinese".
* 🚨 The ENGLISH the user actually sends stays English. This rule is only about
  the explanation around it, never about the message itself.
